# Java ATM Interface Project

## Project Overview
This project is a console-based ATM Interface developed using Java.

## Features
- Transaction History
- Cash Withdrawal
- Cash Deposit
- Money Transfer
- Check Account Balance
- Exit ATM

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE

## Project Structure
- Account.java
- ATM.java
- ATMInterface.java
- BankService.java
- Transaction.java
